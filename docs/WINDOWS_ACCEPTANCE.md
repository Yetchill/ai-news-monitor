# Windows 安装包验收清单

每个候选发布版本均应在一台干净的 Windows 10/11 普通用户账户中完成以下检查。不要复用开发者
已有的 `.env`、数据库或安装目录。

1. 在 [Releases](https://github.com/Yetchill/ai-news-monitor/releases) 下载同一版本的 `Setup.exe` 和 `SHA256SUMS.txt`。
2. 使用下载来源提供的文件校验功能或可信的 SHA-256 校验工具，核对安装包与 `SHA256SUMS.txt`；不一致时停止安装。
3. 以普通用户（非管理员）运行安装程序，确认未出现提升权限请求。
4. 保持默认安装位置，确认它位于当前用户的 `AppData\Local\Programs` 下。
5. 完成安装；默认应创建桌面快捷方式。
6. 确认开始菜单中有应用和卸载入口，桌面快捷方式存在且能启动应用。
7. 首次启动后确认浏览器只打开 `http://127.0.0.1:<随机端口>/`，而不是公网地址。
8. 确认托盘图标出现；使用“打开”可重新打开首页。
9. 打开来源页，确认 canonical 来源目录可见；不应有示例数据库或预置资讯数据。
10. 在来源页显式执行一次更新，确认页面显示运行记录；不要把任何 API Key 填入验收记录。
11. 访问导出功能并生成一个 Excel 或 Word 文件，确认浏览器下载完成且文件可以打开。
12. 在托盘菜单使用“立即更新”“查看日志”和“退出”，分别确认更新启动、日志目录打开、程序正常退出。
13. 再次启动应用，确认之前的数据库和导出仍可用；同时启动第二次时应激活现有实例而不是并发使用同一数据库。
14. 应用运行时再次运行安装程序，确认安装器显示关闭正在运行应用的提示；关闭后继续安装。
15. 从开始菜单卸载应用，确认安装目录和快捷方式删除，而 `%LOCALAPPDATA%\AIIntelligenceMonitor` 中的数据库、日志和导出仍保留。
16. 重新安装同一版本并启动，确认保留的数据可被读取；如有异常，保留日志和版本号后报告。

GitHub Actions 的 Windows packaged integration 会实际构建、检查、静默安装并启动 onedir 程序；
上述步骤仍是发布前的人机交互、托盘和卸载保留数据的补充验收。
